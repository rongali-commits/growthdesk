## FAQ

### Can GrowthDesk use my branding?

Yes. Business identity, colors, approved content, support details, and customer-facing copy are configured for your company.

### Does it replace my existing CRM?

It can replace a lightweight spreadsheet or fragmented service-business workflow. If you require enterprise CRM features or a complex migration, contact me before ordering.

### Does it use AI?

The customer enquiry experience supports controlled approved-answer workflows and can be extended with a buyer-owned AI provider. The core CRM, automation, portal, review, and reporting features work independently.

### Can my clients see each other's information?

No. Each configured client workspace uses its own private portal link and displays only that project's information.

### Can it send real emails or SMS messages?

The product contains the workflow and message sequence. A buyer-owned provider is required for live delivery, and provider fees are separate.

### Is payment processing included?

GrowthDesk can show invoice status and link to a buyer-owned payment page. It does not store payment-card data.
